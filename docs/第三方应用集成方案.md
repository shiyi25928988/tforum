# 第三方应用集成方案

通过导航栏外部链接 + Token 占位符 + Token 校验接口，实现 tForum 与第三方应用的单点登录（SSO）集成。

## 整体流程

```
┌──────────┐   1. 管理员配置外部栏目（含 {token} 占位符）   ┌──────────────┐
│ tForum   │ ──────────────────────────────────────────▶ │ 数据库 nav_item │
│ 管理后台  │ └───────────────────────────────────────── │              │
└──────────┘                                            └──────────────┘

┌──────────┐   2. 用户点击导航栏外部栏目                    ┌──────────────┐
│ tForum   │ ──────── {token} 替换为真实 token ──────────▶ │ 第三方应用    │
│ 前台页面  │   https://app.com/sso?token=eyJhbG...        │ (浏览器跳转)  │
└──────────┘                                            └──────┬───────┘
                                                               │
                                                  3. 第三方应用拿到 token
                                                               │
                                                               ▼
┌──────────┐   4. GET /api/v1/user/verifyToken?token=xxx    ┌──────────────┐
│ tForum   │ ◀────────────────────────────────────────────  │ 第三方应用    │
│ 后端     │ ────── 返回用户信息 / token 无效 ────────────▶ │ (服务端校验)  │
└──────────┘                                                  └──────────────┘
                                                               │
                                                  5. 校验通过 → 建立自己的会话
```

**一句话概括**：管理员在导航栏配置一个带 `{token}` 占位符的外部链接；用户点击时 tForum 自动把当前登录 token 拼进 URL 跳转过去；第三方应用拿到 token 后调 tForum 的校验接口换取用户信息，完成登录。

---

## 第一步：管理员配置外部栏目

1. 以管理员身份登录 tForum，进入 **管理后台 → 导航栏管理**
2. 点击 **新增栏目**
3. 填写：
   - **栏目名称**：例如 `内部工具`
   - **类型**：`外部链接`
   - **链接URL**：`https://your-app.com/sso?token={token}`
   - **排序**、**图标**：按需
4. 保存

> URL 中的 `{token}` 是占位符，用户点击时会被自动替换为当前登录用户的真实 token（URL 编码）。

配置后，该栏目会出现在所有用户（含未登录用户）的顶部导航栏。未登录用户点击时 `{token}` 会被替换为空字符串。

---

## 第二步：tForum 自动替换占位符

这一步由 tForum 前端自动完成，无需第三方做任何事。

当用户点击外部栏目时，tForum 前端会：

```js
// forum/frontend/src/components/Layout.vue
function openExternal(url: string) {
  let finalUrl = url
  if (finalUrl.includes('{token}')) {
    const token = userStore.getToken() || ''
    finalUrl = finalUrl.replace('{token}', encodeURIComponent(token))
  }
  window.open(finalUrl, '_blank')
}
```

例如配置的 URL 是 `https://your-app.com/sso?token={token}`，用户点击后浏览器实际打开：

```
https://your-app.com/sso?token=eyJhbGciOiJIUzI1NiJ9...（当前用户 token）
```

---

## 第三步：第三方应用接收 Token

第三方应用提供一个 SSO 入口页面（或接口），从 URL query 参数中取出 token：

### 示例（任意后端语言通用）

```
GET https://your-app.com/sso?token=eyJhbGciOiJIUzI1NiJ9...
```

第三方应用服务端从 query 里拿到 `token` 参数值。

---

## 第四步：调用 tForum 校验 Token

第三方应用拿到 token 后，调用 tForum 的校验接口换取用户信息。

### 接口定义

```
GET https://tforum-host:8081/api/v1/user/verifyToken?token=<token>
```

**该接口为公开接口**（无需在请求头带 token），专供第三方应用服务端调用。

### 成功响应（token 有效）

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "username": "管理员",
    "account": "admin",
    "email": "admin@example.com",
    "phone": "13800000000",
    "avatar": "...",
    "role": "admin",
    "permission": null,
    "status": "active",
    "token": "eyJhbGciOiJIUzI1NiJ9..."
  }
}
```

### 失败响应（token 无效 / 过期 / 用户不存在）

```json
{
  "code": 1,
  "message": "token 无效"
}
```

> 通过 `code` 字段判断：`0` 为成功，`1` 为失败。

---

## 第五步：第三方应用建立会话

校验通过后，第三方应用根据返回的用户信息建立自己的登录会话（如签发自己的 JWT / 写 Session / 写 Cookie）。

### Java 示例

```java
// 第三方应用服务端伪代码
public UserInfo ssoLogin(String tforumToken) {
    // 1. 调用 tForum 校验接口
    ResponseEntity<Map> resp = restTemplate.getForEntity(
        "https://tforum-host:8081/api/v1/user/verifyToken?token=" + tforumToken,
        Map.class
    );
    Map body = resp.getBody();
    if (body == null || !Integer.valueOf(0).equals(body.get("code"))) {
        throw new RuntimeException("tForum token 无效");
    }
    Map<String, Object> data = (Map<String, Object>) body.get("data");

    // 2. 取出用户信息
    Long userId = Long.valueOf(data.get("id").toString());
    String username = data.get("username").toString();
    String role = data.get("role").toString();

    // 3. 在本系统建立会话（示例：签发自己的 JWT）
    String myJwt = myJwtUtil.sign(userId, username, role);
    return new UserInfo(userId, username, myJwt);
}
```

### Node.js 示例

```js
// 第三方应用 SSO 路由（Express）
app.get('/sso', async (req, res) => {
  const tforumToken = req.query.token
  if (!tforumToken) return res.status(400).send('缺少 token')

  // 1. 调用 tForum 校验接口
  const resp = await fetch(
    `https://tforum-host:8081/api/v1/user/verifyToken?token=${encodeURIComponent(tforumToken)}`
  )
  const body = await resp.json()

  // 2. 校验失败
  if (body.code !== 0) return res.status(401).send('tForum token 无效')

  // 3. 校验通过，建立本系统会话
  const { id, username, role } = body.data
  const myToken = signMyJwt({ id, username, role })
  res.redirect(`/?auth=${myToken}`)
})
```

### Python (Flask) 示例

```python
import requests
from flask import Flask, request, redirect, jsonify

app = Flask(__name__)

@app.route('/sso')
def sso():
    tforum_token = request.args.get('token')
    if not tforum_token:
        return '缺少 token', 400

    # 调用 tForum 校验接口
    resp = requests.get(
        'https://tforum-host:8081/api/v1/user/verifyToken',
        params={'token': tforum_token}
    )
    body = resp.json()

    if body.get('code') != 0:
        return 'tForum token 无效', 401

    user = body['data']
    # 建立本系统会话
    session['user_id'] = user['id']
    session['username'] = user['username']
    return redirect('/')
```

## 安全注意事项

1. **Token 有效期**：tForum 默认 token 有效期 12000 秒（见 `sa-token.yml` 的 `timeout`）。过期后需用户重新登录 tForum。

2. **HTTPS**：生产环境务必全链路 HTTPS，避免 token 在传输中被窃取。

3. **校验必须服务端到服务端**：第三方应用校验 token 时，应由**服务端**调用 `verifyToken` 接口，不要在前端（浏览器）直接调用，否则可能暴露 tForum 后端地址或被绕过。

4. **Token 一次性使用建议**：如果对安全性要求高，第三方应用校验通过后应立即让 tForum 侧使原 token 失效（可扩展接口调用 `StpUtil.logoutByTokenValue(token)`），并签发自己的独立会话 token。

5. **仅放行校验接口**：`/api/v1/user/verifyToken` 已在 `sa-token.yml` 的 `excludePath` 中放行，其他接口仍需认证。不要把更多接口随意放行。

6. **网络隔离**：如果 tForum 与第三方应用在同一内网，`verifyToken` 调用走内网更安全。

## 扩展接口：用户列表与搜索

第三方应用拿到合法 token 后，除了校验 token，还可以调用以下接口查询 tForum 用户，用于在第三方系统中展示用户列表、按名称检索用户等场景。

> 这两个接口**需要登录认证**：调用时必须在请求头带上 token（`token: <token值>`），token 可来自导航栏 `{token}` 占位符跳转，或由 `verifyToken` 接口返回。

### 1. 获取所有用户

```
GET https://tforum-host:8081/api/v1/user/list
Header: token: <token值>
```

成功响应：

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "username": "管理员",
      "account": "admin",
      "email": "admin@example.com",
      "phone": "13800000000",
      "avatar": "...",
      "role": "admin",
      "permission": null,
      "status": "active"
    },
    {
      "id": 2,
      "username": "张三",
      "account": "zhangsan",
      "email": "zhangsan@example.com",
      "phone": "13900000000",
      "avatar": "...",
      "role": "user",
      "permission": null,
      "status": "active"
    }
  ]
}
```

> 列表中的用户项**不返回密码**，且 `token` 字段为空（仅 `verifyToken` / `current` 接口会返回有效 token）。

### 2. 根据用户名或账号模糊查询

```
GET https://tforum-host:8081/api/v1/user/search?keyword=<关键字>
Header: token: <token值>
```

- `keyword` 同时模糊匹配 `username` 和 `account`，二者满足其一即返回。
- `keyword` 为空时返回空列表。

成功响应（`data` 结构与「获取所有用户」一致，为匹配到的用户数组）：

```json
{
  "code": 0,
  "data": [
    {
      "id": 2,
      "username": "张三",
      "account": "zhangsan",
      "email": "zhangsan@example.com",
      "phone": "13900000000",
      "avatar": "...",
      "role": "user",
      "permission": null,
      "status": "active"
    }
  ]
}
```

### 第三方调用示例（Node.js）

```js
// 1. 用 token 拉取全部用户
const resp = await fetch('https://tforum-host:8081/api/v1/user/list', {
  headers: { token: tforumToken }
})
const body = await resp.json()
if (body.code !== 0) throw new Error('获取用户列表失败')
const users = body.data // 用户数组

// 2. 按关键字模糊搜索（匹配用户名或账号）
const r = await fetch(
  `https://tforum-host:8081/api/v1/user/search?keyword=${encodeURIComponent('张')}`,
  { headers: { token: tforumToken } }
)
const matched = (await r.json()).data
```

> ⚠️ **隐私提醒**：这两个接口会返回用户的 `email`、`phone` 等字段。请确保调用方（第三方应用）可信，并按需脱敏存储 / 展示。如需限制只有管理员可调用，可在 Controller 中加 `StpUtil.checkRole("admin")` 校验。

## 接口速查表

| 用途 | 方法 | 路径 | 认证 | 说明 |
|---|---|---|---|---|
| 管理员配置栏目 | POST | `/api/v1/admin/nav/save` | 管理员 | body 含 `type=external`、`url=...{token}` |
| 获取可见栏目 | GET | `/api/v1/nav/list` | 公开 | 前台导航栏渲染用 |
| **第三方校验 token** | GET | `/api/v1/user/verifyToken?token=xxx` | **公开** | **本文档核心接口** |
| 获取当前用户信息 | GET | `/api/v1/user/current` | 需登录 | tForum 内部使用 |
| 获取所有用户 | GET | `/api/v1/user/list` | 需登录 | 第三方可拉取用户列表 |
| 模糊查询用户 | GET | `/api/v1/user/search?keyword=xxx` | 需登录 | 按用户名 / 账号模糊匹配 |

## 常见问题

**Q：未登录用户点击外部栏目会怎样？**
A：`{token}` 会被替换为空字符串，跳转 URL 形如 `https://app.com/sso?token=`。第三方应用校验空 token 时会得到 `token 无效`，应引导用户先去 tForum 登录。

**Q：一个 token 能被多次校验吗？**
A：可以。token 在有效期内可多次调用 `verifyToken`，每次都返回用户信息。如果需要一次性 token，参见上文「安全注意事项」第 4 条。

**Q：tForum 用户修改密码 / 登出后，旧 token 还有效吗？**
A：用户在 tForum 登出后，对应 token 立即失效；修改密码不会自动使旧 token 失效（除非额外实现）。

**Q：如何获取 tForum 的 base URL？**
A：即 tForum 后端服务地址，默认端口 8081。如果通过 nginx 代理，则是前端域名（如 `https://tforum.example.com`），nginx 会把 `/api/` 转发到后端。
